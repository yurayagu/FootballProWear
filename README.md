## Технічна реалізація (Лабораторна робота 3)

У проєкті реалізовано адаптивну верстку з використанням сучасних можливостей **CSS3** без використання сторонніх фреймворків (Bootstrap тощо).

### Використані технології:

1.  **CSS Grid Layout**:

    - Використано для побудови адаптивної сітки товарів (`.products-grid`).
    - Застосовано функцію `repeat(auto-fill, minmax(...))`, що дозволяє карткам автоматично підлаштовуватися під ширину екрану.

2.  **CSS Flexbox**:

    - Використано для побудови навігаційного меню, вирівнювання елементів у хедері та футері.
    - Забезпечує гнучке розміщення елементів карток товару.

3.  **Адаптивність (Responsive Web Design)**:

    - Реалізовано за допомогою медіазапитів (`@media`).
    - Сайт адаптовано для мобільних телефонів (до 480px), планшетів (до 768px) та десктопів.
    - Для мобільних пристроїв розроблено **Бургер-меню** на чистому CSS (через стан чекбокса).

4.  **Стилізація та Валідація форм**:

    - Використано псевдокласи `:valid`, `:invalid`, `:placeholder-shown` для миттєвого зворотного зв'язку користувачу.
    - Реалізовано CSS-анімацію (`@keyframes shake`) для візуалізації помилки при введенні даних.

5.  **Організація коду**:
    - Використано **CSS змінні** (`var(--primary-red)`, `var(--primary-black)`) для підтримки єдиного кольорового стилю відповідно до брендбуку.
    - Стилі розділено на логічні модулі та об'єднано через `@import`.
