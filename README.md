## Технічна реалізація (Лабораторна робота 3)

У проєкті реалізовано адаптивну верстку з використанням сучасних можливостей **CSS3** без використання сторонніх фреймворків (Bootstrap тощо).

### Використані технології:

1.  **CSS Grid Layout**:

    - Використано для побудови адаптивної сітки товарів (`.products-grid`).
    - Застосовано функцію `repeat(auto-fill, minmax(...))`, що дозволяє карткам автоматично підлаштовуватися під ширину екрану.

2.  **CSS Flexbox**:

    - Використано для побудови навігаційного меню, вирівнювання елементів у хедері та футері.
    - Забезпечує гнучке розміщення елементів карток товару.

3.  **Адаптивність (Responsive Web Design)**:

    - Реалізовано за допомогою медіазапитів (`@media`).
    - Сайт адаптовано для мобільних телефонів (до 480px), планшетів (до 768px) та десктопів.
    - Для мобільних пристроїв розроблено **Бургер-меню** на чистому CSS (через стан чекбокса).

4.  **Стилізація та Валідація форм**:

    - Використано псевдокласи `:valid`, `:invalid`, `:placeholder-shown` для миттєвого зворотного зв'язку користувачу.
    - Реалізовано CSS-анімацію (`@keyframes shake`) для візуалізації помилки при введенні даних.

5.  **Організація коду**:
    - Використано **CSS змінні** (`var(--primary-red)`, `var(--primary-black)`) для підтримки єдиного кольорового стилю відповідно до брендбуку.
    - Стилі розділено на логічні модулі та об'єднано через `@import`.

## Технічна реалізація (Лабораторна робота 4: JavaScript)

### Реалізований функціонал:

#### 1. Робота з DOM (Document Object Model):

- **Маніпуляція елементами**:
  - Реалізовано динамічне завантаження деталей товару з масиву даних `productsData`
  - Функція `loadProductDetails()` отримує ID товару з URL-параметрів та заповнює сторінку відповідними даними
  - Використано методи `querySelector`, `getElementById` для доступу до елементів
  - Застосовано `textContent` та `innerHTML` для зміни вмісту елементів
- **Динамічний контент**:
  - Автоматичне створення карток товарів через `createElement` та `appendChild`
  - Функція `loadRelatedProducts()` динамічно генерує секцію схожих товарів
  - Використано template literals для створення HTML-структури
- **Колапсуючі фільтри**:
  - Реалізовано акордеон-меню для фільтрів на сторінці каталогу
  - Функція `initCollapsibleFilters()` додає/видаляє клас `active` при кліку на заголовок фільтра
  - Застосовано `classList.toggle()` для перемикання стану розгортання

#### 2. Обробка подій (Events):

- **Фільтрація товарів**:
  - Функція `initFilters()` додає обробники подій `addEventListener('change')` на всі checkbox-елементи
  - При зміні стану checkbox викликається функція `applyFilters()`
  - Функція `applyFilters()` перевіряє data-атрибути товарів (`data-category`, `data-brand`, `data-price`, `data-model`)
  - Застосовано `style.display` для показу/приховування товарів залежно від вибраних фільтрів
- **Сортування**:

  - Функція `initSorting()` додає обробник `addEventListener('change')` на select-елемент сортування
  - Використано метод `Array.sort()` для сортування масиву товарів за різними критеріями
  - Застосовано `getAttribute('data-price')` для отримання ціни та `parseFloat()` для конвертації у число
  - Після сортування DOM оновлюється через `appendChild()` для зміни порядку елементів

- **Кошик покупок**:
  - Функція `addToCart()` додає товар до кошика та зберігає дані
  - Функція `loadCartItems()` динамічно відображає товари у кошику
  - Event delegation: обробник `addEventListener('click')` на батьківському елементі для кнопок видалення
  - Використано `closest()` для знаходження батьківського елемента картки товару
  - Функція `updateCartTotal()` перераховує загальну суму при будь-яких змінах

#### 3. Валідація форм (Form Validation):

- Функція `initFormValidation()` додає обробник `addEventListener('submit')` на всі форми
- Використано `event.preventDefault()` для блокування стандартної відправки форми
- Функція `validateForm()` перевіряє всі обов'язкові поля через атрибут `[required]`
- **Логіка перевірок**:
  - Перевірка на порожнє поле: `field.value.trim()` видаляє пробіли та перевіряє наявність тексту
  - Email валідація: функція `isValidEmail()` використовує регулярний вираз `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`
  - Візуальний зворотний зв'язок: зміна `style.borderColor` на червоний при помилці
- При успішній валідації виводиться `alert()` з підтвердженням (демо-режим)

#### 4. LocalStorage API:

- **Кошик покупок**:
  - Функція `getCart()` отримує дані з localStorage через `localStorage.getItem('cart')`
  - Використано `JSON.parse()` для конвертації JSON-рядка у JavaScript об'єкт
  - Функція `saveCart()` зберігає кошик через `localStorage.setItem('cart', JSON.stringify(cart))`
  - Дані залишаються після перезавантаження сторінки
- **Лічильник кошика**:
  - Функція `updateCartCount()` відображає кількість товарів у хедері
  - Використано `reduce()` для підрахунку загальної кількості товарів
  - Оновлюється автоматично при будь-яких змінах кошика

#### 5. Додаткові можливості:

- **Вибір розміру**:
  - Функція `loadSizeOptions()` динамічно генерує опції розміру залежно від категорії товару
  - Різні розміри для взуття (UK розміри), одягу (XS-XXL), рукавичок (6-11)
  - Використано `createElement('option')` та `appendChild()` для додавання опцій у select
- **Оновлення кількості**:

  - Функція `updateCartItemQuantity()` змінює кількість товару без перезавантаження
  - Event listener на `addEventListener('change')` для input-полів кількості
  - Реалтайм оновлення ціни через `updateItemTotal()`

- **Плавна прокрутка**:

  - Обробник подій на якірні посилання `a[href^="#"]`
  - Використано `scrollIntoView({ behavior: 'smooth' })` для плавної анімації скролу

- **Контроль введення**:
  - Функція `initQuantityControls()` обмежує значення в полях типу number
  - Перевірка мінімального та максимального значення через атрибути `min` і `max`
  - Автоматичне виправлення при виході за межі дозволених значень

### Використані технології:

- **HTML5 / CSS3** - семантична розмітка та стилізація
- **JavaScript (ES6+)** - стрілкові функції, template literals, деструктуризація
- **DOM API** - `querySelector`, `createElement`, `appendChild`, `addEventListener`, `classList`
- **LocalStorage API** - `getItem`, `setItem`, збереження даних між сесіями
- **Array methods** - `forEach`, `map`, `filter`, `sort`, `reduce`, `find`
- **Event handling** - `click`, `change`, `submit`, `input` події
- **URL API** - `URLSearchParams` для роботи з параметрами URL

### Особливості реалізації:

- Весь код організовано у функції для легкої підтримки та масштабування
- Використано паттерн "модульність" - кожна функція відповідає за конкретну задачу
- Ініціалізація через подію `DOMContentLoaded` гарантує завантаження DOM перед виконанням скриптів
- Обробка помилок через перевірки на існування елементів (`if (!element) return`)
- Відсутність глобальних змінних - всі дані інкапсульовані у функціях
- Використано делегування подій для оптимізації продуктивності
- Адаптивна логіка для мобільних пристроїв з підтримкою touch-подій
